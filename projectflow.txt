1. Verify uv installation on the system by "uv --version" in terminal.

2. Create a dir and open VScode pointing to that dir

3. Execute following command: "uv init ."
 UV ek super fast Python package manager hai (Rust mein likha gaya) jo pip aur virtualenv ka
 alternative hai. Ye tumhe dependencies install karne, virtual environments banane, aur projects manage 
 karne mein madad karta hai.
 "uv init ." command tumhare folder ko ek Python project workspace bana deta hai. Current directory (.) 
 mein ek UV project initialize karta hai.
 Ek pyproject.toml file create hoti hai → isme tum apne dependencies define kar sakte ho.

 4. Execute following command: "uv add fastmcp" -> fastmcp is a sdk which make very convieniently to create
 MCP Servers.
 uv.lock file create hoti hai → reproducible builds ke liye.
 .venv is created via uv since we are using uv to add MCP AND INSIDE ALL DEPENDENCIES HAS BEEN ADDED
  BY uv.

 5. Execute following command-> ".venv\Scripts\Activate.ps1"

 6. Verify fastmcp installation: "fastmcp version"
 FastMCP version:                                                                           4.1.3
MCP version:                                                                               2.3.0
Python version:                                                                           3.11.9
Platform:                                                              Windows-10-10.0.26200-SP0
FastMCP root path: D:\IITPatna\GenAI-DEV-Projects\MCP-SERIES-LOCALSERVER\.venv\Lib\site-packages

7. Add server code to main.py

8. Command to run inspector -> "npx @modelcontextprotocol/inspector uv run python main.py"
fastmcp internally supports this evaluation SDK or module which allows you to run this inspector object
to test your MCP server. it acts as a client as it allows you to test before connecting with actual client.

9. Command to run mcp server -> "uv run fastmcp run main.py"

10. "uv run fastmcp install claude-desktop main.py" -> edit config of claudedesktop (open it via Aditya Kumar
-> Settings -> Developer (in bottom) -> Edit Config)

** Steps to deploy our MCP server **
-------------------------------------
**Optional Steps A-H**
A> Create a new folder & open in VSCode
B> Install & verify uv installation: "where uv" or "uv version"
C> Execute the command "uv init ."
D> Run -> "uv add fastmcp"
E> Activate the project venv before working: -> ".venv\Scripts\Activate.ps1"
F> Verify: "fastmcp version"
G> Add code to main.py file
H> Also test on MCP inspector by doing: 
Terminal1: "uv run python main.py"
Terminal2: "npx @modelcontextprotocol/inspector uv run python main.py"

I> Git Setup after creating a new github repo:
git init
git add README.md
git add .
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/vikashishere/remote-mcp-helpdesk-server.git
git push -u origin main

J> create a requirements.txt -> fastmcp -> add this file to github and merge it with main.
K> Go to railway.com, signup & auth with github, select the repo & deploy
L> Click on the service card -> deployment -> logs; to check if app is running or not
M> Service card -> settings -> find: networking -> if no public domain exists, click -> Generate Domain
(it will create something like: https://your-app-production.up.railway.app)

N> Add this domain to our custom connect as: https:domain/mcp -> then just restart claude
for example, copied from railway.com : https://your-app-production.up.railway.app/mcp
